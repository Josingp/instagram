촬영용 SNS 화면 설정

    촬영 모드에서는 설정 버튼이 사라집니다. Esc 키를 누르거나 화면 오른쪽 위 모서리를 빠르게 3번 클릭하면 설정으로 돌아옵니다.

    프로필

    숫자는 입력한 그대로 표시됩니다. 예: 1,234 / 2.4만 / 153만. 촬영 중 팔로우 버튼이나 하트를 클릭하면 상태와 숫자가 실제처럼 바뀝니다.
